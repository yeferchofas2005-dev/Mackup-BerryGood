# Paleta de colores - OrangeDev

Esta es la paleta base para OrangeDev, una marca enfocada en desarrollo de software, productos digitales y tecnología aplicada.

## 1) Paleta principal

| Nombre | Hex | Uso recomendado |
|---|---|---|
| Orange | `#FF7A18` | Color principal, CTA, iconografía y elementos destacados |
| Orange Light | `#FF9A3D` | Acentos, hover y micro-interacciones |
| Orange Dark | `#C94F00` | Profundidad y contrastes más fuertes |
| Berry Purple | `#6D16C7` | Color de conexión y soporte con la marca madre |
| Background principal | `#111318` | Base general oscura |
| Background secundario | `#191C23` | Superficies secundarias |
| Cards | `#222631` | Paneles y contenedores |
| Texto principal | `#F5F5F7` | Títulos y texto principal |
| Texto secundario | `#A7ABB5` | Descripciones y textos secundarios |

## 2) Variables CSS sugeridas

```css
:root {
  --orange: #FF7A18;
  --orange-light: #FF9A3D;
  --orange-dark: #C94F00;
  --berry: #6D16C7;
  --bg-primary: #111318;
  --bg-secondary: #191C23;
  --surface: #222631;
  --text-primary: #F5F5F7;
  --text-secondary: #A7ABB5;
}
```

## 3) Guía de uso

### Color principal
- `#FF7A18` representa tecnología, desarrollo y productividad.
- Se recomienda usarlo en:
  - botones de acción
  - iconos de software
  - líneas y bordes destacados
  - indicadores y acentos visuales

### Color de apoyo
- `#FF9A3D` aporta brillo y energía sin perder profesionalismo.
- Se usa para:
  - hover
  - degradados suaves
  - pequeños detalles de destaque

### Fondo y texto
- Fondo oscuro para transmitir seriedad técnica y claridad visual.
- El morado corporativo de BerryGood ayuda a conectar la marca con el ecosistema.

## 4) Ejemplo de composición visual

```css
body {
  background: #111318;
  color: #F5F5F7;
}

.primary-btn {
  background: #FF7A18;
  color: #111318;
}

.feature-card {
  background: linear-gradient(135deg, #FF7A18, #6D16C7);
  color: #F5F5F7;
}
```

## 5) Recomendación general

OrangeDev debe sentirse técnico, moderno y profesional. El naranja debe ser el acento principal, mientras que el morado corporativo refuerza la conexión con la identidad de BerryGood y con el resto de aplicativos del grupo.
