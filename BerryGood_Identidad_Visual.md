# BerryGood — Sistema de Identidad Visual y Paleta de Colores

## 1. Objetivo

Definir una identidad visual coherente para **BerryGood** y sus tres líneas de servicio:

- **BerryGood** — Marca principal / ecosistema tecnológico.
- **BananoMarketing** — Marketing digital y bots.
- **OrangeDev** — Desarrollo de software y productos digitales con modalidad de suscripción.
- **Lemon.ia** — Inteligencia artificial, bots y automatizaciones.

La idea principal es que las cuatro identidades sean claramente diferenciables, pero que visualmente pertenezcan al mismo ecosistema empresarial.

---

# 2. Concepto general

BerryGood debe proyectar:

- Tecnología
- Innovación
- Modernidad
- Confianza
- Creatividad
- Crecimiento
- Inteligencia artificial
- Desarrollo de software
- Marketing digital

La web debe tener una estética **moderna, tecnológica, elegante y premium**, evitando una apariencia infantil o excesivamente colorida.

Se recomienda utilizar un **tema oscuro como base**, aprovechando el morado presente en el logo de BerryGood.

La estructura visual debe funcionar de esta forma:

```text
                         BERRYGOOD
                             |
          +------------------+------------------+
          |                  |                  |
         🍌                 🍊                 🍋
   BananoMarketing       OrangeDev          Lemon.ia
      Marketing          Software              IA
       Amarillo           Naranja             Lima
```

Las submarcas deben utilizar colores propios, pero compartir los fondos, tipografía, estructura, componentes y lenguaje visual de BerryGood.

| Uso | HEX |

## Regla importante

Los colores de las submarcas NO deben reemplazar completamente los colores neutros.

La base de toda la página debe mantenerse oscura:

```text

Background secundario: #191C23
Cards: #222631
Texto principal: #F5F5F7
Texto secundario: #A7ABB5
```

Los colores de cada marca funcionan como **acentos visuales**.

# 9. Regla de consistencia visual

Las submarcas deben diferenciarse por el color de acento, NO por diseños completamente diferentes.

Todos deben compartir:

- Fondo oscuro
- Tipografía
- Bordes
- Radios
- Cards
- Navbar
- Footer
- Animaciones
- Sistema de botones
- Sistema de espaciado
- Sistema de iconos

Ejemplo:

```text
BerryGood       → Morado
BananoMarketing → Amarillo
OrangeDev       → Naranja
Lemon.ia        → Lima

Todos            → Negro + Gris + Blanco
```

Esto permitirá que el usuario entienda que está navegando dentro de diferentes servicios de una misma empresa.

---

# 10. Gradientes

Los gradientes deben combinar el color de cada submarca con el morado corporativo de BerryGood.

## BerryGood

```css
linear-gradient(135deg, #3B0870, #6D16C7, #8B2BE2);
```

## BananoMarketing

```css
linear-gradient(135deg, #F5C542, #6D16C7);
```

## OrangeDev

```css
linear-gradient(135deg, #FF7A18, #6D16C7);
```

## Lemon.ia

```css
linear-gradient(135deg, #DFFF3F, #6D16C7);
```

No utilizar gradientes en absolutamente todos los elementos. Deben utilizarse principalmente en:

- Hero
- Ilustraciones
- Backgrounds decorativos
- Botones especiales
- Cards destacadas
- Efectos visuales

# 21. Regla de oro

**BerryGood es el ecosistema.**

Los colores de las submarcas sirven para comunicar sus especialidades:

- Morado = BerryGood / tecnología general
- Amarillo = Marketing / crecimiento
- Naranja = Software / desarrollo
- Lima = IA / automatización

No crear cuatro páginas visualmente independientes.

La experiencia debe hacer sentir al usuario:

> "Estoy dentro de BerryGood y estoy explorando diferentes soluciones de la empresa."

Implementar la identidad en este orden:

1. Variables CSS globales.
2. Fondo y colores generales.
3. Tipografía.
4. Navbar.
5. Hero BerryGood.
6. Cards de servicios.
7. Sección BananoMarketing.
8. Sección OrangeDev.
9. Sección Lemon.ia.
10. Botones y estados hover.
11. Animaciones.
12. Footer.
